Path Planner Help & Documentation

Welcome to the VEX V5 LemLib Path Planner

An interactive path planning tool and discrete kinematics simulator designed for competitive VEX V5 robotics teams running LemLib on the Override 2026-27 field.

🎯 Field Coordinates & Conventions

  • Field Dimensions: 144" × 144" (-72" to +72" in X and Y).
  • Field Center: (0, 0) is the exact center intersection.
  • Heading System: 0° is facing +Y (North / upward), 90° is facing +X (East / right), Clockwise positive (CW+).
  • Tile Grid: 6 × 6 foam tiles, each 24" × 24".

⚡ 3-Step Quick Start

  1. Position Start: Drag the green START robot along the perimeter wall to match your legal starting tile.
  2. Add Moves: Use the + Add dropdown to add actions like moveToPose or swingToPoint.
  3. Simulate & Export: Press ▶ Simulate to preview authentic differential-drive execution, then copy the auto-generated C++ code.
💡 Pro Tip: Cloud synchronization is enabled with Google Sign-In! You can plan routines on your laptop, save them to the cloud, and open them directly in the pit area.

LemLib Motion Commands Reference

Each movement in your autonomous routine corresponds directly to an official LemLib chassis method:

moveToPoint chassis.moveToPoint(x, y, timeout, options);

Drives the chassis straight to target coordinate (x, y) using coupled lateral and angular PID controllers. Automatically turns toward the target while driving.

moveToPose chassis.moveToPose(x, y, theta, timeout, options);

Boomerang pursuit algorithm! Dynamically guides the robot toward a moving "Carrot" pursuit point determined by the lead parameter (default 0.6). Produces smooth, arc-based trajectories ensuring the robot arrives at (x, y) pointing in direction theta.

turnToPoint chassis.turnToPoint(x, y, timeout, options);

Turns the robot on the spot so the front (or rear if reversed) points directly at (x, y). Displays an aim reticle with dashed sightline on the field.

turnToHeading chassis.turnToHeading(theta, timeout, options);

Turns in place to an absolute field heading theta [0°–359°] using LemLib angular PID.

swingToPoint chassis.swingToPoint(x, y, lockedSide, timeout, options);

Locks one wheel side (LEFT or RIGHT) and powers the other wheel to swing until facing (x, y). Features 22.5° snapping and rotation radius axis dragging.

swingToHeading chassis.swingToHeading(theta, lockedSide, timeout, options);

Swings about the locked wheel until the robot's heading reaches the target angle theta.

Custom Code // C++ code snippet

Injects subsystem commands directly into the autonomous sequence, such as intake.move(127);, clamp.set_value(true);, or pros::delay(250);.

Interactive Canvas & Gestures

🖐️ Mouse & Touch Dragging

  • Start Robot: Click and drag the green robot icon. It automatically snaps to the perimeter wall per VRC rules.
  • Waypoints: Click and drag any numbered waypoint on the field to reposition it.
  • Aim Reticle: For swingToPoint and turnToPoint, drag the target crosshair directly on the field.
  • Selecting: Click any card in the flowchart or click its point on the canvas to select and highlight it.

🎯 Swing Radius Dragging & 22.5° Snapping

  • Rotation Radius Axis: When dragging a swingToPoint target reticle, movement is projected along the forward radial ray from the chassis.
  • 22.5° Angle Snapping: The swing angle automatically snaps to standard 22.5° increments (0°, 22.5°, 45°, 67.5°, 90°, etc.).
  • Free-Angle Dragging: Hold the Shift key while dragging to bypass snapping for arbitrary angles.
  • Locked Pivot Marker: Displays a golden dot at the locked wheel pivot coordinate.

🎨 Canvas Legend & Visual Indicators

Green: Starting position & heading indicator.

Blue Line: Forward path simulated by LemLib differential kinematics.

Orange Line: Reverse motion path (when forwards: false).

Carrot Marker: Dynamic Boomerang pursuit point for moveToPose.

Cyan Crosshair: Aim target and dashed sightline for swing/turn to point.

Robot Kinematics & Simulation

The simulator implements an authentic 10ms discrete integration loop modeling real differential-drive physics:

⚙️ Drivetrain Parameters

  • Track Width: Center-to-center distance between left and right drive wheels in inches (typically 10"–13"). Used for angular velocity calculations $\omega = (v_R - v_L) / \text{trackWidth}$.
  • Robot Width & Length: Physical robot bounding box in inches. Drawn to scale on the field to check game element clearance.
  • Wheel Diameter & RPM: Used to compute max theoretical forward speed $v_{\max} = \pi \times d \times (\text{RPM}/60)$.

📈 Dynamics & Controller Emulation

  • Motor Slew Rate: Simulated acceleration limit with first-order filter time constant ($\tau = 0.07\text{s}$) to avoid unrealistic instantaneous velocity jumps.
  • PID Controllers: Emulates LemLib's lateral and angular PID controllers with proportional scaling and integral error tracking.
  • Early Exit Range: Set earlyExitRange in inches to blend sequential movements without stopping to a complete standstill.

LemLib C++ Code Integration

Export your autonomous routines directly into your PROS project:

// In src/main.cpp
void autonomous() {
    // 1. Set starting pose on the field
    chassis.setPose(-60.0, -60.0, 0);

    // 2. Execute planned movements
    chassis.moveToPoint(-36.0, -36.0, 2000);
    chassis.waitUntilDone();

    chassis.swingToPoint(20.0, -30.0, lemlib::DriveSide::LEFT, 2000);
    chassis.waitUntilDone();

    // 3. Custom subsystem actions
    intake.move(127);
    pros::delay(300);
}

Export Modes & Options

  • Current routine: Generates clean code for just the currently active autonomous tab, beginning with the routine header and chassis starting pose.
  • All routines (switch): Generates a complete switch (autonSelector) block containing all routines in your project.
  • Indentation: Choose 2 spaces (standard), 4 spaces (PROS default), 0 spaces, 1 tab, or a custom number of spaces to match your team's code style.
  • Multitasking (Async): When enabled, appends , true as LemLib's async parameter so motions run non-blocking in the background while custom subsystem code (intake, lift, clamp) executes concurrently.
