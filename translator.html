C++ Parser Specification & Technical Reference

Deterministic AST tokenization, LemLib v0.5+ parameter extraction, and autonomous slot binding protocol.

1. Tokenization and Method Mapping

The parser scans C++ source for LemLib motion primitives including moveToPoint, moveToPose, turnToHeading, and subsystem invocations. It extracts poses, velocity caps, and parameters into atomic action blocks.

2. LemLib Struct Support

Fully resolves designator structs containing .forwards, .maxSpeed, .minSpeed, .earlyExitRange, and .lead, allowing exact reproduction in the 2D simulation environment.

3. Asynchronous Concurrency Analysis

Detects non-blocking subsystem tasks and {.async = true} flags, structuring parallel execution branches so intakes and pneumatics fire without pausing chassis odometry tracking.

4. Routine Target Ingestion

Applying writes the parsed AST sequence directly into the active slot or new autonomous profile. Changes immediately register across both local storage and cloud persistence.
