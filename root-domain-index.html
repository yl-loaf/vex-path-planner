About the VEX V5 LemLib Suite

The VEX V5 LemLib Suite provides high school and collegiate robotics teams competing in the VEX Robotics Competition (VRC) with advanced autonomous motion profiling. Leveraging LemLib's pure pursuit algorithms and odometry tracking, users can build reliable 15-second autonomous win-point routines and 60-second programming skills runs on the Override game field.

Designed for teams using PROS 3 and PROS 4 with modern C++, this suite combines visual drag-and-drop spline editing with direct source code synchronization, USB V5 Brain telemetry streaming, and automated Google Drive autonomous backups.
